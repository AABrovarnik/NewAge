# ADR format

Use: `Status`, `Date`, `Context`, `Decision drivers`, `Options considered`, `Decision`, `Consequences`, `Security`, `Operations`, `Migration/Rollback`, `Open questions`. Link evidence and issue/PR IDs. Save drafts locally first; publish to Drive or GitHub only after confirmation.
