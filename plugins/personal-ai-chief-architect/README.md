# Personal AI Chief & Architect

Локальный Codex-плагин для персонального мультиагента с двумя основными ролями:

- **Secretary** — входящие сообщения, календарь, задачи, документы и follow-up.
- **Architect** — требования, ADR, системный дизайн, риски, GitHub delivery.

## Принципы

1. Сначала план и подтверждение, затем внешняя запись.
2. По умолчанию только чтение для почты, календаря, Drive и GitHub.
3. Любое отправление письма, публикация, merge, удаление или изменение встречи требует явного подтверждения.
4. Все решения и внешние действия журналируются в `state/` (локальный каталог, не коммитить секреты).

## Интеграции

Конфигурационные точки описаны в `.mcp.json` и `docs/integrations.md`. Для production подставьте свои MCP-серверы или адаптеры через переменные окружения; credentials не хранятся в этом пакете.

## Запуск

```bash
python3 scripts/preflight.py
python3 scripts/run_loop.py morning-briefing --dry-run
python3 scripts/run_loop.py inbox-triage --dry-run
```

Сценарии и политика подтверждений находятся в `loops/` и `policies/`.

## Публикация

`Posts/` в корне проекта содержит публикационный пост с описанием пакета. Перед push настройте remote GitHub и проверьте `.gitignore`.
